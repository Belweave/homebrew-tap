# Belweave Homebrew tap

## Jiggle Mode

Edit your iPhone or iPad Home Screen from your Mac, or let an AI agent do it.
More at [jigglemode.com](https://jigglemode.com/).

```sh
brew install --cask belweave/tap/jigglemode
```

Update later with `brew upgrade --cask jigglemode`. Remove with
`brew uninstall --cask jigglemode`.
