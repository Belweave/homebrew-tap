# Belweave Homebrew tap

## Console Cast

Bring a PS5® or Xbox Series X|S® console's built-in broadcast into OBS Studio™ on your Mac, with no capture card.
More at [consolecast.app](https://consolecast.app/).

```sh
brew install --cask belweave/tap/console-cast
```

Update later with `brew upgrade --cask console-cast`. Remove with
`brew uninstall --cask console-cast`.

Questions: info@belweave.com

## Jiggle Mode

Edit your iPhone or iPad Home Screen from your Mac, or let an AI agent do it.
More at [jigglemode.com](https://jigglemode.com/).

```sh
brew install --cask belweave/tap/jigglemode
```

Update later with `brew upgrade --cask jigglemode`. Remove with
`brew uninstall --cask jigglemode`.

Questions: hello@jigglemode.com
